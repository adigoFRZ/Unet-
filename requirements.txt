# ---- PyTorch ------------------------------------------------------------- #
# NOT listed above on purpose: the CUDA build has to match the installed driver,
# so it is installed from the PyTorch index rather than PyPI. Installing plain
# `torch` from PyPI would silently pull a differently-linked build.
#
# The build used here (RTX 4070 Laptop, driver 566.07 reporting CUDA 12.7) is cu126.
# Install it with whichever interpreter is active -- on Windows that is
# .venv\Scripts\python.exe, on Linux/macOS it is .venv/bin/python:
#
#   python -m pip install torch --index-url https://download.pytorch.org/whl/cu126
#
# CPU-only machines can drop --index-url entirely.
#
# Verified working build (do not change without re-running the GPU smoke test):
#   torch 2.14.0+cu126  |  CUDA runtime 12.6  |  cuDNN 91002  |  sm_89
